# Solar Controller Homey v1.0.1 — Final App Store Review

- Patch release following the initial v1.0.0 upload.
- Store description clearly states that the Homey app requires the complete Solar Controller installation.
- ESP32 firmware plus suitable power-control hardware, such as a Kemo M240, are described as part of the required system.
- Official Solar Controller project homepage is configured as https://github.com/glijie/solar-controller-firmware
- Functional Homey/ESP32 integration remains unchanged.
- Automatic LAN discovery/mDNS remains deliberately deferred.
